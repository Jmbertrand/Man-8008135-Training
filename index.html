THE BOARD
This week

How to run it

Spacing
Mon / Wed / Fri, or any pattern with a rest day between.
Order
Top to bottom. Hardest lifts while fresh, core last so a tired midsection doesn't wreck your squat form.
Effort
Stop 1–3 reps short of failure. Take the last set of push-ups and core all the way.
Progress
Beat last session's number in the yellow line. One more rep, or the same reps with more weight.
Stuck
No heavier dumbbells? Lower for 3 seconds, pause 2 at the bottom, or go one limb at a time.
