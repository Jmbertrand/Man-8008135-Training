THE BOARD
dumbbells · floor · couch
3 days / week

How to run it

Spacing
Mon / Wed / Fri, or any pattern with a rest day between sessions.
Order
Top to bottom, always. The hardest lifts come first while you're fresh; core sits last so a tired midsection doesn't wreck your squat and RDL form.
Effort
Stop each set 1–3 reps short of failure. On push-ups and core, take the last set all the way.
Progress
Add one rep per set each week. Once you hit the top of the range on every set, add weight and drop back to the bottom.
Stuck
No heavier dumbbells? Slow the lowering to 3 seconds, pause 2 seconds at the bottom, or go one limb at a time. Same stimulus, same weight.
